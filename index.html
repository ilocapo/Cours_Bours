Installer un contenu

  1. Télécharge le fichier

    Chaque bouton ouvre la page de son créateur. Pense à le créditer si tu partages des captures.

  2. Place-le dans le dossier Mods

    Copie les fichiers .package et .ts4script dans Documents/Electronic Arts/Les Sims 4/Mods.

  3. Active les mods de script

    Pour les mods uniquement : Options du jeu, onglet Autres, puis « Activer les mods de script ». Relance le jeu.
