# Project Structure

## Root (convention only)

- README.md
- requirements.txt
- .gitignore

## Main folders

- `src/` : Python modules and business logic
- `scripts/` : executable workflows by domain
- `data/runtime/` : runtime CSV/JSON inputs and state
- `docs/` : static web app + project docs
- `output/` : generated reports/exports
- `archive/` : legacy and historical files

## Scripts taxonomy

- `scripts/trading/`
- `scripts/automation/`
- `scripts/fundamentals/`
- `scripts/maintenance/`
- `scripts/guides/`
- `scripts/platform/windows/`
- `scripts/platform/unix/`
- `scripts/entrypoints/legacy/`
