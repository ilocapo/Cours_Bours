# Sims 4 Afrique

Catalogue de CC et de mods Sims 4 inspirés de l'Afrique : aperçus en galerie, téléchargement en un clic, mises à jour et filtre par pays.

Site statique : ouvrir `index.html`, ou publier avec GitHub Pages (Settings, Pages).
Pour ajouter un contenu ou une mise à jour, modifier uniquement `data.js`.

Site de fans, non affilié à Electronic Arts ni à Maxis. Les Sims est une marque d'Electronic Arts Inc.
