# ZST Beauty Center — site vitrine

Next.js (App Router, TypeScript), GSAP + Lenis. Cahier des charges : `CLAUDE.md`.

```bash
npm install
cp .env.example .env.local   # NEXT_PUBLIC_BOOKING_URL = lien Planity / Fresha
npm run dev
```

Données (rituels, catégories, horaires, personnel, coordonnées) : `src/data/*.ts`.
Les tarifs, l'adresse et les horaires sont à compléter.
