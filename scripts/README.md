# Scripts reorganisés

## Dossiers

- `scripts/trading/` : scripts métier trading (signaux, portfolio, dashboard data, scheduler).
- `scripts/automation/` : orchestration journalière/hebdomadaire.
- `scripts/fundamentals/` : scraping fondamental et alertes CORE.
- `scripts/maintenance/` : patching, parsing, utilitaires de maintenance.
- `scripts/guides/` : génération et mise à jour des guides Excel.
- `scripts/platform/` : scripts OS (`windows`, `unix`).
- `scripts/entrypoints/legacy/` : anciens wrappers déplacés hors racine.
